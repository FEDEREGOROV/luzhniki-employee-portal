# Внутренний портал «Лужники»

Локальный интерактивный прототип портала сотрудников.

## Запуск

Откройте `index.html` напрямую в браузере или запустите локальный сервер из этой папки:

```bash
python3 -m http.server 8080
```

Затем откройте <http://localhost:8080>.

## Разделы

- главная страница с новостями, днями рождения и новыми сотрудниками;
- структура компании с поиском и карточками подразделений;
- каталог новых сотрудников с фильтрами;
- календарь дней рождения;
- информация о компании;
- личный кабинет с локальным сохранением профиля.

Данные в прототипе демонстрационные. Для промышленной версии потребуется подключение к корпоративным источникам данных и системе авторизации.
